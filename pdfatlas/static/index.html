    Topics

    Found a posteriori: k-means on document vectors, named by the words that are frequent inside a cluster and rare outside it (c-TF-IDF). Image clusters are named zero-shot by SigLIP. The topics are re-fitted as the corpus grows.

      §05

      Labels

      Your own categories. Draw a region on Fig. 1 with Lasso ✎ (or Shift+drag) and name it: every document inside it gets the label. On the image map, a figure inside the region labels the document it belongs to. Labels belong to whole PDFs (stored by file path), and a document can carry any number of them. Export CSV ↓

          §06

          Sources

          The folders being watched. PDFs that appear in them are indexed automatically. To add a completely new folder, give its absolute path as seen from the server. It becomes a new collection and is indexed within a few minutes (watch the progress bar). Needs the admin password, which is checked on the server.
